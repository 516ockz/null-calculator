このツールについて

kW と A の換算、電圧降下の目安を素早く確認するための社内ツール 現場で迷わないために標準条件は固定

操作の流れ

  • Mode で計算内容を選ぶ（kW→A / A→kW / V-drop）
  • 必要な項目を入力して Calculate
  • Copy result で結果をコピーしてLINEなどに貼れる

入力項目の意味

  • 電圧（V） 使う電圧（例 100 / 200 / 400）
  • 単相 / 三相 電源の種類（家庭系は単相、動力は三相が多い）
  • 距離（m） 電圧降下用の片道距離
  • sq 電線の太さ（断面積）

結果の見方

  • 大きい数値 が計算結果（A / kW / 電圧降下率）
  • Status が OK / NG の目安（社内基準）

計算条件（標準 固定）

  • 施設条件 ラック敷設
  • 周囲温度 30℃
  • 力率 0.85
  • 効率 0.90
  • 設計マージン 10%
  • 電圧降下 簡易式（抵抗ベース / Cu想定）

注意

配管、多条敷設、高温環境など条件が違う場合は別途検討 最終判断は現場条件と図面に合わせてお願いします
